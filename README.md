# Landing Page - Psicóloga Derly Chitiva

Este es un sitio web profesional y minimalista diseñado para la psicóloga **Derly Chitiva**. El objetivo principal es proporcionar una presencia en línea que transmita confianza, profesionalismo y facilite el contacto con potenciales pacientes.

## 🚀 Características

- **Diseño Responsivo:** Optimizado para dispositivos móviles, tablets y computadoras de escritorio, con menú lateral animado y backdrop en móviles.
- **Navegación Intuitiva:** Secciones claras de "Sobre Mí", "Servicios", "Testimonios" y "Contacto", con resaltado de la sección activa al hacer scroll.
- **Llamados a la Acción (CTA):** Botones estratégicos con mensaje predefinido para agendar citas vía WhatsApp, incluido botón flotante.
- **Formulario de Contacto:** Validación en el cliente que arma y envía el mensaje directo a WhatsApp.
- **Accesibilidad:** Navegación por teclado, foco visible, atributos ARIA y soporte para `prefers-reduced-motion`.
- **Animaciones Suaves:** Entrada de secciones con IntersectionObserver al hacer scroll.
- **SEO:** Meta description, Open Graph, Twitter Cards y favicon propio.
- **Estética Profesional:** Paleta de colores suaves que promueven la calma y el bienestar emocional.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica para mejor SEO y accesibilidad.
- **CSS3:** Estilos modernos utilizando Flexbox, Grid, variables CSS y animaciones.
- **JavaScript (Vanilla):** Menú móvil, animaciones de scroll, validación del formulario y navegación activa.
- **Font Awesome:** Iconografía.
- **Google Fonts:** Tipografías 'Montserrat' y 'Open Sans' para legibilidad superior.

## 📦 Instalación y Preview Local

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Galking-droid/pagina-psicologia.git
   ```
2. Abre el archivo `index.html` en tu navegador preferido o utiliza la extensión **Live Server** en VS Code para desarrollo en tiempo real.
